# 📚 Module 2 — JavaScript Fundamentals & Practice

### 🎯 Goal

Module 2 focuses on developing a stronger understanding of JavaScript fundamentals through **conditions, calculations, and problem-solving practice**.

### 🧠 Topics Covered

* JavaScript Expressions
* Conditional Statements
* `if`
* `else`
* `else if`
* Comparison
* Logical Operators
* `&&`
* `||`
* `!`
* Nested Conditions
* Problem Solving
* Practice Tasks
* Real-world Programming Examples

### 💻 Example

```javascript
const age = 20;

if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are not an adult.");
}
```

### 🔍 Logical Operator Example

```javascript
const age = 20;
const hasID = true;

if (age >= 18 && hasID) {
    console.log("You can enter.");
} else {
    console.log("Entry denied.");
}
```
